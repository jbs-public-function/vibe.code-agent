# Agent Guidance

All agent-facing material for this repository lives under **`.zed/docs/`**.

This includes (but is not limited to):

- **Steering docs** — project conventions, workflows, and behavioral guidance.
- **Skills** — modular, reusable instructions for specific tasks.
- **Reference material** — any other documentation intended for LLM agents rather than humans.

## How to use it

1. **Before making changes**, read the relevant files under `.zed/docs/` to pick up any
   conventions, constraints, or task-specific instructions that apply.
2. **When you need to know where something is documented**, look in `.zed/docs/` first.
3. **When adding agent-facing guidance**, write it under `.zed/docs/` rather than scattering
   it elsewhere in the repo (or adding it to this file).

## Note

This file is only a pointer. Keep it short; do not add detailed rules here — put them in
`.zed/docs/` so there is a single, discoverable home for agent guidance.
